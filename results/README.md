# results/

Generated by the Colab notebook (Section 6). The website reads these files:

| File | Content |
|---|---|
| `metrics.json` / `metrics.csv` | Test-set metrics (detection, image-level, latency) |
| `thresholds.json` | Confidence / NMS-IoU tuned on the validation split |
| `threshold_tuning_val.csv` | Validation grid search |
| `training_results.csv` | Per-epoch training / validation losses and metrics |
| `dataset_report.json` | Dataset conversion and split report |
| `*.png` | Curves and charts |

No numbers in this folder are hand-written. If the files are missing, the dashboard says so.
